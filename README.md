# VO₂ 자동 측정 프로그램

천장 카메라로 판 위의 샘플을 찾고, 핀을 내려 접촉한 뒤 히트건으로 데우고 식히면서 온도–저항을 재는 프로그램이다(v3).
위쪽 메뉴 넷: **초기 설정**(처음 한 번) · **자동 측정** · **측정 결과** · **수동 제어**. 구조 · 하드웨어 값 · 안전 규칙 · 저장 형식은 CLAUDE.md 에 있다.

## 설치
```
pip install -r requirements.txt
```
측정 장비(K2110 · K2450)는 NI-VISA 가 필요하다. 없으면 그 장비만 "드라이버 없음"으로 표시하고 프로그램은 계속 돈다.

## 실행
```
python run.py                # 창(최대화). 시작할 때 저장된 포트 · 주소에 자동 연결한다
python run.py --no-window    # 서버만(브라우저로 http://127.0.0.1:8000)
python run.py --port 8001    # 서버 포트 바꾸기(기본 8000)
```
- 설정은 프로그램 폴더의 `settings.json`(git 제외, 없으면 기본값). 데이터 · 로그는 `..\data_v3`.
- **Esc 는 어디서든 비상정지**다. 화면 오른쪽 위의 [비상정지]도 같다. 비상정지는 릴레이 · K2450 출력을 끄고 해제할 때까지 이동 · 릴레이 · 측정을 잠근다.
  - 정지 중에는 같은 버튼이 [비상정지 중 · 해제] 로 바뀌고 화면 위에 빨간 띠가 뜬다.
  - 해제: 그 버튼이나 Esc → 확인 창 "비상정지 해제?" → [해제] 또는 Enter. [취소] 또는 Esc 는 창만 닫는다. 정지 뒤 2초 동안은 해제할 수 없다.
  - 해제해도 릴레이 · K2450 출력은 꺼진 채, 멈춘 이동은 버려진 채, 측정은 중지된 채다(위치와 릴레이 상태만 다시 읽는다).
- 이동만 멈추려면 이동 패드 가운데의 **[정지]**. 잠그지 않고 릴레이 · 출력도 그대로 두므로 바로 다시 움직일 수 있다(측정 중에는 [측정 중지] 또는 비상정지).

## 처음 쓰는 순서
초기 설정 탭의 1~7단계를 위에서부터 한 번 한다. 끝낸 단계에는 ✓ 와 저장한 값이 보인다. 순서를 강제하지는 않는다(안 되는 버튼은 회색 + 이유).

| 단계 | 하는 일 |
|---|---|
| 1 장비 연결 | 스테이지 포트 · 온도계 · 저항계 · 카메라를 선택 상자에서 하나씩 골라 [연결]. 목록은 이 컴퓨터의 것이고 [새로고침]으로 다시 읽는다. 다음부터는 자동으로 연결된다 |
| 2 원점 설정 | "현재 위치를 원점으로": 세 축을 모터 쪽 끝에 붙인 후 [X 등록] · [Y 등록] · [Z 등록] 또는 [전체 등록]. 또는 "끝단 접촉 원점" [X] · [Y] · [Z](0 쪽 끝으로 최대 5 mm 밀고 2 mm 물러난 위치가 0 - 끝에서 5 mm 안쪽일 때만). X · Y 는 Z 원점이 먼저 있어야 한다. 아래 한 줄은 연결 때 보드가 알려 준 위치 기억("마지막 저장 위치 복원" · "지난 종료 때 위치 저장 안 됨 · 원점 다시 설정") |
| 3 카메라 · 판 영역 | 헤드가 판을 가리지 않고 헤드 마커가 보이는 위치로 옮겨 [현재 위치로 설정] → (처음 한 번 · 카메라를 바꾼 뒤) "초점" 의 [초점 찾기]: 샘플을 올려 둔 채 판 영역 안이 가장 선명한 초점 값을 찾는다(헤드 마커 둘레는 뺌 · 판 영역이 없으면 [범위 상자] 로 사진에 상자) → 그래프 확인 · 필요하면 [−] [+] → [적용]. 초점이 바뀌면 판 영역은 다시 [확정] · 빈 판 사진 · 헤드 마커 · 보정 점은 다시 해야 한다 → [촬영] → 사진에서 판에 새겨진 사각형의 꼭짓점 A · B · C · D 를 왼쪽 위부터 시계 방향으로 누르고 [확정]. 사진이 작으면 [크게 선택]: 휠 확대 · 오른쪽 끌기(또는 스페이스 + 끌기) 이동 · [＋] [－] [맞춤] · 돋보기 · 점 끌기 · 방향키 1 px(Shift 10 px) · 변 길이 차이로 잘못 찍은 점 확인 |
| 4 빈 판 사진 | 샘플을 올리지 않은 판을 [빈 판 촬영](없어도 측정은 되지만 샘플을 더 잘 찾는다) |
| 5 좌표 보정 | 왼쪽 이동 패드로 핀을 꼭짓점 A~D 에 차례로 대고 오른쪽 [A 등록] … [D 등록](작은 안내 그림: A = 안쪽 왼쪽 · 시계 방향 · 등록된 점은 채움 · 이름은 문 기준 화면 이름). 4번째 등록 뒤 헤드 마커는 자동 등록. 더 맞추고 싶으면 수동 제어 탭 카메라의 "판 사진"(마지막으로 찍은 판 사진 · 십자 · 사각형 = 핀)에서 [클릭 이동]으로 간 뒤 조그로 맞추고 [보정 점 추가] → 큰 사진에서 핀이 실제로 있는 자리를 눌러 [추가](같은 자리 3 mm 안이면 그 점을 교체 · [마지막 지우기]) · 보정 점만 지울 때는 [보정 점 모두 지우기](꼭짓점 · 마커까지 지우는 것은 "꼭짓점 등록" 칸 [좌표 보정 초기화] · 둘 다 확인 창) |
| 6 접촉 높이 설정 | 핀을 작은 단위(0.01 · 0.05 · 0.1 · 1 mm)로 내려 샘플에 댄 뒤 [현재 높이로 저장]. 측정은 이 높이까지만 내린다(접촉 방식 = 고정 높이). 접촉 방식을 "전기 탐색"으로 바꾼 때에만 [접촉 탐색] → [높이 저장] 이 보인다 |
| 7 쿨러 배치 | 왼쪽 "켜 보기": 쿨러 릴레이(기본 R2 · R3 · R4)를 하나씩 켜서 냉각되는 칸을 확인. 오른쪽 "칸 정하기": [R2] [R3] [R4] [비우기] 중 하나를 고르고 칸을 누른다(쿨러를 켜지 않아도 됨 · 누를 때마다 저장 · 같은 릴레이가 든 칸을 다시 누르면 비움 · 켜 본 릴레이가 처음 고른 값). 같은 릴레이를 여러 칸에 둘 수 있다. 칸은 문 기준(아래 = 문 · 네 구석에 A~D)으로 보인다. 빈 칸이 있으면 "빈 칸 n개"(미완료)이고, 쿨러 "샘플 아래 구역" 이면 빈 칸의 샘플은 측정을 시작하지 않는다. 처음에는 "기본 배치 · 확인 필요" |

그다음 **자동 측정** 탭:
1. 샘플을 올리고 [촬영 · 샘플 검출]. 판 사진과 순서 표에서 잴 샘플을 고른다("미확인" · "핀보다 작음"은 제외된 채로 나온다. 샘플을 누르고 [포함] · [제외]).
2. 필요하면 [조건]에서 전압 · 온도 · 반복 · 쿨러 · NAS 폴더를 바꾼다. 이름은 순서 표에서 더블클릭으로 고친다.
3. [측정 시작]. 빠진 초기 설정이 있으면 버튼 옆에 무엇이 빠졌는지와 그 단계로 가는 글자가 보인다.
4. 도중에 [건너뛰기] · [완료 후 정지] · [측정 중지]를 쓸 수 있다. 멈춘 뒤에는 [측정 재개] 또는 [전체 재측정]. 끝난 샘플 하나만 다시 재려면 그 샘플을 누르고 [재측정].
5. 끝나면 [결과 보기] → **측정 결과** 탭에서 그래프(3개까지) · 표 · 저장 파일 · NAS 복사 상태를 본다.

설정 값 전체는 초기 설정 탭 왼쪽 목록 맨 아래 **전체 설정**에서 보고 고친다("실장비 확인 필요" 표시가 있는 값은 측정 PC 에서 확인해야 한다).
항목 이름(ⓘ)에 마우스를 올리면 설명(뜻 · 언제 바꾸는지 · 단위 · 기본값)이 뜬다. 데이터 폴더 · NAS 폴더는 [찾아보기]로 고를 수 있다(창으로 실행했을 때만 - `--no-window` 에는 없다).

## 펌웨어 V18 업로드 (열선 출력 0.1 % · 고르게 켜기 · 전원 주기 단위 칸 · 열선 박자 · 전원 맞춤 기준 · 켜는 순간 돌리기)
측정 · 온도 시험 · 수동 열선 출력은 펌웨어 V18(`firmware/stage_v18/stage_v18.ino`)가 필요하다. V11 ~ V17 이면 연결은 되지만(이동 · 쿨러) 그 일들은 "펌웨어 V18 필요" 로 거절된다.
V18 이 V17 에서 바뀐 점: **켜는 순간 돌리기** `hpr <0~999>`(‰ · 보고 HP 줄 끝 `G=`) - 전체 설정 "켜는 순간 돌리기"(기본 0 = 끔 · 382 권장).
열선 SSR 을 켜는 순간이 전원 파형의 어디에 걸리느냐에 따라 그 켜짐 한 덩어리의 열이 1 배 아니면 약 2 배로 들어온다(11/23 실측: 300 ms 칸 톱니 +1.4 °C 또는 +3.0 °C).
틱이 전원 반주기와 거의 같아 켜는 순간의 위치가 천천히 밀리고(약 9 s 에 반주기) 출력이 높아 칸이 자주 켜지면 2 배가 몇 초씩 연달아 나와 열이 덩어리진다.
전원 신호를 받지 않고(부품 · 배선 추가 없음) 켤 때마다 켜는 순간을 반주기의 그 ‰ 만큼 뒤로 미뤄 1 배 · 2 배가 고르게 섞이게 한다(켜져 있는 길이는 그대로).
전원 맞춤 기준이 없음이고 열선 박자가 전원 맞춤일 때만 돈다(그 밖이면 프로그램이 0 을 보낸다 · [박자 시험] 은 시험 동안 0). 출력 방식 글 끝에 " · 돌리기 382 ‰".
V17 이 V16 에서 바뀐 점: 열선을 켜고 끄는 틱을 전원 파형에 붙잡는 방법 셋(전체 설정 "전원 맞춤 기준"으로 골라 하나씩 시험).
[환경 맞추기] 의 출력 훑기에서 출력만 올려도 온도가 약 9 초마다 +3~9 °C 계단으로 올랐다 - 틱이 전원 반주기와 약 0.1 % 어긋나 켜는 순간의 전원 파형 위치가
약 9 초에 반주기씩 밀리고, 그 위치에 따라 열이 잘 들어가는 상태와 덜 들어가는 상태가 갈린다.
- **영점 모듈**(`hpz 1`): 영점 감지 모듈의 신호에 틱을 맞춘다. 배선 = 모듈 VCC → 5V · GND → GND · OUT → **D19**.
- **전선**(`hpz 2`): **A0** 에 꽂은 전선 한 가닥이 줍는 60 Hz 잡음에 틱을 맞춘다(다른 끝은 비워 둔다).
- **없음 + 타이머 보정**(`hpz 0` · `hpt <ppm>`): 기준 신호 없이 틱 길이를 ppm 단위로 미세 보정한다(온도 시험 [박자 보정] 이 정한다).
- 전원 위상 `hpo <0~999>`(‰ - 기준 신호의 영점에서 켜는 순간까지 · 온도 시험 [위상 찾기] 가 정한다) · 상태 `hz`("HZ Z=1 L=1 F=5998 …" - 기준 · 잠김 · 주파수 · 세기 · 위상 오차) · HP 줄 끝 `Z= L=`.
- 기준이 없음이 아니면 "열선 박자" 설정은 쓰지 않는다(전원 맞춤으로 보낸다). 기준을 골랐는데 잠기지 않으면 온도 시험 · 자동 측정 시작이
  "전원 맞춤 신호 없음 · 영점 모듈(D19) 확인"(또는 전선(A0))으로 거절된다. 상태 한 줄은 온도 시험 창 진행 줄 아래 · 수동 제어 히트건 칸에 보인다.
V16 이 V15 에서 바뀐 점: 열선 박자 `hpj <0|1|2>`(0 전원 맞춤 = V15 그대로 · 1 어긋남 = 틱 1/64 길게 · 2 무작위 = 틱 0.5~1.5 배) · 보고 HP 줄 끝 `J=`.
틱이 전원 반주기와 거의 같아 켜는 순간의 전원 파형 위치가 약 10 초 주기로 밀리고 그 주기로 열이 덩어리져 들어오는 것으로 보여서 넣었다. 설정 "열선 박자"(기본 전원 맞춤).
V15 가 V14 에서 바뀐 점:
- 칸 = 전원 주기의 정수배(한 주기 17 ms 부터 · 33 · 50 · 100 · 300 …) - 제로크로스 SSR 이 한 번 켤 때 켜지는 양이 항상 같다(10 ms 칸은 반주기 1 개 또는 2 개라 출렁였다).
- 0 에서 켤 때 첫 칸을 억지로 켜지 않음(V14 는 hp 0.1 마다 300 ms 칸을 통째로 켜 냉각 끝에서 3~5 °C 씩 튀었다).
- 누적을 지우지 않음(출력 0 · 방식 · 칸을 바꿔도 그대로).
50 Hz 지역이면 파일 위쪽 `MAINS_HZ = 60` 을 50 으로 바꿔 올린다.
(V14 = 출력 0.1 % 단위 · 출력 방식 몰아 켜기 / 고르게 나눠 켜기. 정수 % 는 1 % ≈ 1.3 °C 계단이었고, 5 s 주기 몰아 켜기는 30 % 에서 ±3 °C 출렁였다.)
(V12 는 출력 % 를 받을 때마다 주기를 처음부터 다시 시작해, 0.5 s 마다 % 를 보내는 램프 제어에서 열선이 사실상 계속 켜졌다. V13 은 주기 위치를 유지하고 비율만 바꾼다.)
1. LabVIEW 와 이 프로그램을 모두 끈다(COM5 를 다른 프로그램이 잡고 있으면 업로드가 안 된다).
2. 아두이노 IDE 에서 `firmware/stage_v18/stage_v18.ino` 를 연다(폴더 이름과 파일 이름이 같아야 한다).
3. 도구 → 보드: **Arduino Mega or Mega 2560** · 프로세서 ATmega2560 · 포트: **COM5**(COM4 는 다른 장비 - 고르지 않는다).
4. [업로드]. 끝나면 시리얼 모니터(115200 · 새 줄)에서 `=== 3-AXIS V18 ===` · "열선 출력: 전원 60 Hz · 틱 8.33 ms … · 박자 0(전원 맞춤) · 기준 없음" 와 EEPROM 줄을 확인하고 시리얼 모니터를 닫는다.
   위치 기억(EEPROM) 형식은 V11 ~ V17 과 같아서 전에 저장한 위치가 그대로 복원된다.
5. 프로그램을 켜고 초기 설정 1 의 스테이지 줄에 "펌웨어 V18" 이 보이는지 확인한다.
6. 온도 시험 창에서 [히트건 맞추기] 를 한 번 한다(고르게 켜기 칸 · 출력별 온도 표 · 열 모델을 정해 설정에 저장 - 약 25~30분).
   그 뒤 스테이션 다이얼 · 쿨러 같은 환경을 바꾸면 [환경 맞추기] 한 번(약 15~20분 · 표 · 열 모델만 다시 잼 · 확인 시험까지).

## 알아 둘 동작
- **화면 방향 = 문 기준**: 모든 사진 · 판 그림 · 이동 패드는 문 밖에서 안을 보는 방향이다(아래 = 문 = X 먼 쪽 · 위 = 안쪽 · 왼쪽 = Y 모터 쪽 · 오른쪽 = Y 먼 쪽).
  사진 칸 둘레에 방향 글. 카메라 사진은 실제로는 180° 뒤집혀 있어 화면에서만 돌린다(전체 설정 "사진 화면 회전" 180° · 장비 값 - 저장된 값은 그대로).
  꼭짓점 이름도 화면 기준(A = 안쪽 왼쪽부터 시계 방향). 이동 패드 버튼은 "안쪽 X−" · "문 X+" · "왼쪽 Y−" · "오른쪽 Y+". 샘플 번호는 화면 왼쪽 위부터(설정 "샘플 번호 시작").
- **카메라 안정 대기**: 이동 · 초점 변경 뒤 사진은 1 초 기다린 뒤 연속 두 장이 같아질 때까지 기다려 쓴다(카메라 프레임이 늦게 온다). 8 초 안에 안 멈추면 "카메라 화면 안정 안 됨".
- **샘플 배치**: 전체 설정 "샘플 배치" 기본 자유(보이는 샘플만). 격자로 바꾸면 행 · 열 격자로 빈 자리를 "미확인" 으로 예측한다. 판 사각형 밖 샘플은 내지 않는다. 샘플 줄에 크기(긴 변 × 짧은 변).
  "약한 샘플 다시 찾기"(기본 끔)를 켜면 흐릿한 샘플을 낮은 기준으로 한 번 더 찾는다(얼룩도 잡을 수 있어 찾은 것은 확인 필요 · 기본 제외).
- **사진 밀림**: 샘플 검출 때 빈 판 사진 대비 밀림(X · Y mm · 회전)을 로그에 남기고 "사진 밀림 알림 기준"(1 mm)을 넘으면 알림(좌표는 고치지 않는다 · 카메라 · 판 확인).
- **수동 제어 이동**: [지금 위치](좌표 칸 채움) · [접촉 높이로 내리기](현재 X · Y 에서 접촉 높이까지 · 확인 창) · [클릭 이동] 은 실시간 보기에서도 켜고 켜면 판 사진 보기로.
- **샘플 이동 · 자동 순회**(수동 제어 탭 카메라 "판 사진" 아래 줄 - 히트건 · 쿨러 없이 "샘플 인식 → 이동 → 접촉" 을 본다):
  [◀ 이전] [샘플 선택] [다음 ▶] = 그 샘플의 핀 놓을 자리로 이동(핀 맨 위 → X · Y · 순서는 샘플 표 · 선택된 샘플은 윤곽 굵게).
  "이동 후 내리기"(화면 값 · 켤 때 확인 창 · 접촉 높이 · Z 원점 필요)를 켜면 샘플로 간 뒤 위치를 다시 읽어(0.05 mm 안) 접촉 높이까지 내린다(마지막 저속 하강 거리는 느리게) -
  판 사진 · [크게 보기] 에서 샘플을 눌러도 같다(샘플이 아닌 자리는 내리지 않는다). 이동 도중 [정지] · 비상정지면 내리지 않는다.
  [자동 순회](확인 창) = 포함 샘플을 차례로 이동 → 접촉 높이 → "순회 머무는 시간"(3 s) 머묾 → 다음(핀 맨 위로 올린 뒤) · 끝나면 핀 맨 위. 저항계가 연결돼 있고 "접촉 후 저항 기록" 이면
  샘플마다 저항을 한 번 기록(판정 없음) · 진행 "순회 3/10 · 1-3 · 접촉 높이" · 끝나면 결과 목록(이름 · 저항 또는 "기록 없음") · 로그 샘플마다 한 줄.
  [순회 정지] · 이동 패드 [정지] = 남은 샘플을 버리고 핀 맨 위 · 비상정지 = 핀을 움직이지 않고 끝. 히트건이 켜져 있거나 원점 · 좌표 보정 · 접촉 높이가 없으면 시작하지 않는다.
  순회 중에는 측정 중처럼 손으로 하는 이동 · 릴레이 · 측정 · 설정 변경을 막는다(읽기 · [순회 정지] · [정지] · 비상정지만).
- **열선 출력 % 제어**: 열선(R10 · SSR)을 켜기/끄기 대신 출력 % 로 조절한다(배율 × 앞먹임 + PI · 가열 · 냉각 같은 제어). 계수는 열 모델에서 자동으로 정한다.
  열선 줄(SSR + 스테이션)은 명령한 % 를 그대로 통과시키지 않아서(같은 % 라도 칸에 따라 열이 2~3배 다름) 유지 출력 · 이득은 실제로 잰 **출력별 온도 표**에서 읽는다.
  처음 한 번(또는 히트건 · 쿨러를 바꾼 뒤) 온도 시험 [히트건 맞추기] 로 칸 · 출력별 온도 표 · 열 모델(τ · θ)을, [최대 속도 재기] 로 5 °C 구간별 최대 가열 · 냉각 속도를 잰다.
  표나 열 모델이 없으면 "열 모델 없음 · 온도 시험 [히트건 맞추기] 필요" 주의가 뜬다. "제어 응답 시간"(기본 5 s)이 클수록 느슨하다.
  히트건이 내는 열이 스스로 2 배쯤 바뀌어도 따라가게 표에서 읽은 출력에 곱하는 **배율**을 실시간으로 배운다(다음 샘플 · 시험이 이어받음 · 프로그램을 켜면 1 ·
  [히트건 맞추기] · [환경 맞추기] 가 표를 새로 저장하면 1).
  PI 는 온도 흔들림 한 주기("제어 평균 창" 8 s) 평균 오차로 계산한다.
  **온도 급변**: 온도가 목표선에서 "온도 급변 기준"(4 °C) 넘게 벗어나면 배율을 바로 한 단 바꾸고 샘플 메모 · 온도 시험 메모 · 로그에 "온도 급변 · 가열 61 °C" 로 남긴다(측정은 계속).
  설정 속도가 최대 속도보다 빠르면 시작 때 주의(막지 않음).
- **속도 = 점 간격 또는 걸리는 시간**("속도 정하는 방법"): 점 간격(기본)이면 "목표 점 간격"(기본 0.27 °C)과 측정 간격으로 정한다(속도 = 점 간격 ÷ 측정 간격 × 60).
  "냉각 속도 따로" 를 켜면 냉각만 다른 속도. 걸리는 시간이면 "가열 시간" · "냉각 시간"(기본 102 s)으로 정한다(속도 = 온도 차 ÷ 시간 × 60 · 측정 간격과 무관 · 0.1 ~ 600 °C/분).
  측정 [조건] · 온도 시험 창 "조건" 에 예상 점 수 · 시간이 보인다. 측정 간격은 읽기 시간 예상보다 짧게 넣을 수 없다.
- **결과**: 가열 · 냉각 점 수(시작~끝 온도 구간) · 실제 평균 속도 · 점 간격 흔들림 · 역전(가열 중 내려감 · 냉각 중 올라감 - 기준 0.3 °C) · 목표선 차이 ·
  온도 흔들림(30 s 창의 직선 추세를 뺀 나머지의 크기 · 폭 · 가장 센 주기 2~30 s · 진폭)이 측정 화면 · summary.csv · run.json · 온도 시험 창 · summary.txt 에 남는다.
  온도 시험은 끝날 때마다 `temp_test\index.csv` 에 한 줄(조건 · 결과 · 메모)을 덧붙여 시험끼리 비교할 수 있다.
- **스테이션 켠 뒤 100 % 유지**: 가열 장치(957DW 핫에어 스테이션)는 켜진 직후 열선을 끊으면 H-E 로 멈춘다. 그래서 스테이션을 새로 켜면 5 초 동안 열선 100 % 로 두고, 그동안의 출력 % 는 끝날 때 적용한다("스테이션 켜는 중 · n초 뒤 출력 적용"). 끄기 · 비상정지는 바로. 열선 출력 주기 기본 5 초.
- **히트건 맞추기**(온도 시험 창): 스테이션을 켜고 송풍만으로 식혀 기준 온도를 잡은 뒤, 후보 칸(기본 20 · 30 · 70 · 100 · 150 · 200 · 300 ms)마다
  같은 비교 온도(기본 55 °C)에 출력을 맞추고 1분 동안 흔들림을 재서 가장 작은 칸을 고른다. 그 칸 · 맞춘 출력에서 위 · 아래 여러 단(단마다 90 s)으로
  출력별 온도 표와 열 모델(τ · θ)을 잰다. 끝까지 가면 칸 · 표 · 열 모델을 설정에 저장한다. 출력 30 % 이상인데 3 °C 도 안 오르면 "가열 안 됨 · H-E 의심" 으로 멈춘다.
- **환경 맞추기**(온도 시험 창 [환경 맞추기]): 스테이션 다이얼 · 쿨러 같은 환경을 바꾼 뒤 한 번 누르면 사람 손 없이 이어진다.
  기준 온도(출력 0 % 로 더 안 내려갈 때까지 · 최대 5분) → 출력 훑기(지금 출력 방식 그대로 0 % → 최대 출력 "훑기 올림 시간"(기본 120 s) → "훑기 꼭대기 유지"(기본 20 s) → 같은 속도로 0 % → 20 s) →
  기록 전체로 1차 지연 + 정지 곡선(11마디)을 맞춰 출력별 온도 표 · 열 모델(τ · θ)을 저장 → 새 표로 가열 · 냉각 확인 시험([시작] 과 같음).
  천장 온도(꼭대기 뒤쪽 절반 평균)가 가열 끝 온도 + 1 °C 에 못 미치면 확인 시험 없이 "스테이션 설정 온도 올리기" 로 끝난다(표는 저장됨). 차단 온도 − 8 °C 에 닿으면 그 자리에서 내린다.
  출력만 올릴 때 · 내릴 때의 직선성(직선 차이 · 흔들림 · 역전)도 창 · summary.txt [환경 맞추기] 에 남긴다. 출력 방식 · 칸은 바꾸지 않는다.
- **박자 시험**(온도 시험 창 [박자 시험]): 스테이션을 켠 뒤(예비 냉각 없음) 지금 출력 방식 · 칸 그대로 열선 박자만 전원 맞춤 → 어긋남 → 무작위로 바꿔
  박자마다 "박자 시험 출력"(기본 20 %)으로 "박자 시험 유지"(기본 60 s) 동안 기록한다. 박자마다 뒤쪽 2/3 에서 직선 추세를 뺀 평균 · 흔들림 · 폭 · 가장 센 주기(2~30 s)와 진폭을
  창 · summary.txt [박자 시험] 에 남긴다. 설정은 저장하지 않는다(좋은 박자는 전체 설정 "열선 박자" 로 직접 고른다). 끝나면 박자를 시작 전 값으로 되돌린다.
  전원 맞춤 기준이 없음일 때만 시작한다.
- **유지 시험 안정 대기**(박자 시험 · 위상 찾기 · 박자 보정 공통 · "유지 시험 안정 대기" 기본 60 s · 0 = 안 함): 첫 출력을 넣은 뒤 한 번, 첫 기록 전에 기다린다.
  스테이션을 켠 뒤 100 % 유지로 80 °C 근처까지 튄 온도가 유지 출력의 온도로 내려오는 동안이 첫 구간에 섞이면 박자 보정의 박자 주기 · 위상 찾기의 첫 위상 평균이 틀렸다.
  이 구간은 temp.csv 에 단계 "안정" 으로만 남고 계산에는 쓰지 않는다. 세 시험 모두 걸리는 시간이 이만큼 늘어난다.
- **위상 찾기**(온도 시험 창 [위상 찾기] · 전원 맞춤 기준이 영점 모듈 · 전선일 때만): 스테이션을 켠 뒤 "박자 시험 출력"으로 전원 위상 0 · 100 · … · 900 ‰ 마다
  잠길 때까지(최대 5 s) 기다리고 "위상 찾기 유지"(기본 30 s) 동안 기록 → 뒤쪽 2/3 의 평균 · 흔들림 · 폭 · 주기 · 잠김.
  이웃 위상의 평균 차이가 전체 폭의 35 % 를 넘는 곳을 경계로 보고 가장 긴 구간의 가운데 위상을 "전원 위상" 에 저장한다(전체 폭 2 °C 미만이면 흔들림이 가장 작은 위상).
- **박자 보정**(온도 시험 창 [박자 보정] · 기준 없음일 때만): 타이머 보정 0 → +600 ppm 마다 "박자 보정 유지"(기본 45 s) 동안 기록해 박자 주기를 재고
  어긋남 = 1e6 ÷ (120 × 주기) ppm 의 부호를 두 주기로 정해 반대로 보정 → 그 보정으로 한 번 더 확인 → "타이머 보정" 에 저장. 보정 0 에서 박자가 안 보이면(진폭 0.5 °C 미만) 멈춘다.
- **히트건 기록**: 히트건을 켜면 어떤 일이든 `<데이터 폴더>/heater_log/` 에 기록이 남는다(꺼진 뒤 60 초까지 · 온도 · 출력 % · 출력 방식 · 송풍 · 열선 · 쿨러 · 하는 일).
- **수동 제어 히트건**: [켜기](열선 → 송풍) · [끄기](열선 끔 → 송풍 30초 뒤) · [즉시 끄기](열선 · 송풍 바로) · 열선 출력 % [적용](송풍이 켜진 동안만).
- **설정 저장**: settings.json 에는 기본값과 다른 값만 저장한다. 쿨러 배치 · 릴레이 배선 · 초점 값 · 장비 방향은 이 장비의 값이 코드 기본값이다(배선 · 설치가 바뀌면 코드를 고친다).
  포트 · 주소 · 폴더 · 카메라 번호 · 촬영 위치 · 접촉 높이는 PC 값(전체 설정에 "PC 값" 표시). 예전 기본값 그대로 저장된 값(예: 측정 전압 1.0 V)은 시작할 때 새 기본값으로 바뀐다(로그 한 줄).
  전체 설정 위 [설정 내보내기](바꾼 값만 json) · [가져오기](바뀔 항목을 보고 [적용] · "PC 값 제외" 기본 켬).
- **닫을 때 핀 맨 위**: 창을 닫거나 [연결 끊기] 하면 릴레이를 끈 뒤 핀을 맨 위로 올리고 위치를 저장한다(비상정지 잠금이면 움직이지 않는다).
- **창 닫기 확인**: 창 X 를 누르면 "프로그램 종료" 창에 닫을 때 하는 일이 보인다(측정 · 온도 시험 중이면 맨 위에 경고). [종료] 로 닫고 [취소] 는 그대로. `--no-window` · Ctrl+C 는 묻지 않는다.
- **자동 이동 전 확인**: 이동 버튼이 아닌데 모터가 움직이는 버튼(끝단 접촉 원점 · 촬영 · 초점 찾기 · 빈 판 촬영 · 4번째 꼭짓점 등록과 마커 등록 · 접촉 탐색 · 측정 시작 · 재개 · 재촬영)은
  누르면 먼저 "무엇 때문에 · 어떻게 움직이는지" 창이 뜬다. [진행] 을 눌러야 움직인다(Enter 로는 진행 안 됨). 전체 설정 "자동 이동 전 확인" 을 끄면 묻지 않는다.
- **빈 판 사진 비교**: 초기 설정 4 에 마지막 판 사진이 나란히 보인다. 샘플 검출은 빈 판 사진의 밝기를 맞춘 뒤(채널별 중앙값 배율 - 샘플이 많아도 안 흔들림) 비교하고, 그래도 안 맞으면 밝기 차이 · 잔차 · 이동을 숫자로 보인다(조명 · 문 상태 확인).
- **헤드 마커 등록 검사**(허용은 mm - 기본 0.5 mm): 두 장 촬영 일치 · 촬영 위치로 돌아와 같은 위치 · 두 방향 직각 · 크기 비 · 판 배율 대비 크기 · 판 기준 방향이 하나라도 어긋나면 저장하지 않고 이유를 보인다.
- **원점 유지**: 보드는 위치를 저장(save)한 뒤 움직이지 않았을 때만 다시 켤 때 원점을 되살린다. 프로그램은 창을 닫을 때 · [연결 끊기] · 측정이 끝났을 때
  이동을 멈추고 릴레이를 끈 뒤 위치를 저장한다. 비상정지를 풀지 않고 닫으면 저장하지 않는다(다음에 원점 다시). 작업 관리자 강제 종료 · 정전 · USB 빠짐도 다음에 원점이 없다.
- **릴레이**: R1 = 히트건 송풍 · R10 = 히트건 열선 · R2 · R3 · R4 = 쿨러 3묶음(하나에 쿨러 3개) · R5~R9 미배정. 번호는 전체 설정 "릴레이" 에서 바꾼다
  (릴레이를 모두 끈 뒤에만 · 셋이 겹치면 거절). 장비 앞에서 본 방향(전체 설정 "장비 앞쪽" · "장비 오른쪽" - 기본 X 먼 쪽 · Y 먼 쪽)은 초기 설정 7 의 칸 방향에만 쓴다. 예전 설정 파일의 히트건 릴레이 · 쿨러 9개 배치는 시작할 때 새 형식으로 옮기고 로그에 적는다(쿨러 배치는 초기 설정 7 다시 확인).
- **히트건 켜는 순서**: 송풍을 먼저 켜고 열선을 켜면 히트건이 오류를 낸다. 프로그램은 언제나 **열선 → 1초 뒤 송풍** 순서로 켜고(송풍이 이미 켜져 있으면 열선만),
  끌 때는 **열선을 바로 끄고 송풍은 30초 뒤**에 끈다(열선 식힘). 개별 릴레이 버튼 · 직접 명령으로는 송풍 · 열선을 켤 수 없다. 비상정지는 전부 바로 끈다.
  히트건(송풍 또는 열선)이 켜진 동안 X · Y 이동은 거절된다. 안전 판단(차단 온도 · 온도 못 읽음 · 열선 연속 최대 시간)은 열선만 바로 끈다.
- **가열 · 냉각 방식**(전체 설정 "가열 제어" · 측정 [조건] · 온도 시험 창): 기본은 둘 다 **속도 제어**(3 °C/분 · 같은 속도) - 송풍을 켜 둔 채 열선을 켜고 꺼서
  목표선을 따라 오르고(시작 온도 → 가열 끝 온도) 내려온다(가열 끝 → 냉각 끝 온도). 가열 · 냉각 곡선 모두 점이 촘촘하고 같은 속도라 두 곡선을 같은 조건에서 비교한다.
  가열 끝 온도에 닿으면 유지 시간(기본 0초) 뒤 냉각. **계속 가열** · **자연 냉각** 은 예전 동작(냉각 중 송풍 설정은 자연 냉각에만).
  온도가 목표선보다 3 °C(목표선 기다림 폭) 넘게 뒤처지면 목표선이 기다린다(히트건이 못 따라갈 때 · 자연 냉각이 느릴 때).
  자동 측정 탭 오른쪽에 "목표 52.3 °C · 열선 켜짐"(기다리면 "목표 대기") · 점 간격 "점 n개 · 평균 0.05 °C 마다 1점" 이 보이고,
  점마다 목표 온도 · 열선 · 송풍이 `<이름>_<전압>V_control.csv` 에 남는다. 측정 [조건] 창에 예상 시간(가열 · 냉각 · 전체)이 보인다.
- **시작 온도**: 가열은 시작 온도 이하에서만 시작한다(회차마다). 쿨러로 시작 온도까지 못 식으면 측정 전체가 멈추고("시작 온도 미도달 · 쿨러 · 주위 온도 확인 필요")
  그 샘플은 대기로 남는다 - 쿨러 · 주위 온도를 확인하고 [측정 재개]. 냉각이 냉각 끝 온도 전에 멈추면 "냉각 끝 온도 미도달" 주의(기록은 그대로).
- **온도 시험**(수동 제어 탭 릴레이 시험 [온도 시험]): 샘플 · 저항계 · 모터 없이 히트건 · 쿨러 온도만 잰다.
  쿨러 켬 → 스테이션 켜기(켠 뒤 5 초 100 % 유지로 85~104 °C 까지 튐) → 예비 냉각(송풍만 · 출력 0 % · 시작 온도까지 · 못 닿으면 중단) → 가열 → 냉각(자동 측정과 같은 가열 · 냉각 방식 · 설정) → 끔. 점 간격도 결과에 보인다. 도달 표(5 °C 마다 걸린 시간) · 평균 가열 속도 · 넘침 · 냉각 시간.
  [정지] · 비상정지 · 안전 차단에도 기록 저장: `<데이터 폴더>	emp_test\YYYYMMDD_HHMMSS\` temp.csv · summary.txt · graph.png.
  시험 중에는 자동 측정 · 접촉 탐색 · 히트건 · 쿨러 버튼 · 설정 변경 불가. 창을 닫아도 계속된다.
- **수동 제어 탭**: 왼쪽 카메라 · 이동, 오른쪽 수동 측정 · 릴레이 시험 · 직접 명령. 장비가 연결되지 않았으면 그 장비가 필요한 버튼이 꺼지고 이유가 한 줄 보인다.
- **접촉 방식**(전체 설정 "접촉" · 측정 [조건]): 기본은 **고정 높이** - 저장한 접촉 높이까지 정확히 내리고 끝낸다. 내린 뒤 저항을 한 번 재서 기록만 한다(판정 없음).
  **전기 탐색**은 선택 사항 - 전류를 보며 0.1 mm 씩 더 내린다(저장 높이 − 0.3 mm 에서 시작 · 저장 높이 + 0.5 mm 아래로는 내리지 않는다). 판단 기준은 모두 전체 설정에 있다.
- **저항계(K2450)는 한 번에 한 기능만** 쓴다: 접촉 탐색 · 1회 측정 · 연속 측정 · 자동 측정 · 직접 명령. 쓰는 중에 다른 것을 누르면 "저항계 사용 중 · …" 으로 거절한다.
  접촉 탐색과 측정 시작은 연속 측정을 먼저 끈다.
- **직접 명령은 읽기 · 조회만** 된다. 스테이지는 `st` · `p` · `rs` · `wd` · `?`, 측정 장비는 `…?` 조회만(출력 · 설정 · 재기는 버튼으로). `!` 는 비상정지.
- **수동 Z 하강 한도**(전체 설정 "이동", 기본 끔): 켜면 수동 조그 · 좌표 이동이 한도 아래로 가는 명령을 통째로 거절한다. 접촉 높이 기준(접촉 높이 − 0.3 mm) 또는 고정 값.
  실장비에서 내려도 되는 높이를 확인한 뒤 켠다. 지금 한도는 초기 설정 6 화면에 보인다.
- **X · Y 조그 잠금**(전체 설정 "이동" "X · Y 조그 여유 높이" 0.5 mm · 0 = 끔): 핀이 접촉 높이 − 0.5 mm 보다 아래면 X · Y 조그를 거절한다("Z … mm 위로 올리기" · 이동 패드의 X · Y 버튼만 꺼짐).
  Z 를 올리면 풀린다. 접촉 높이 · Z 원점이 없으면 막지 않는다. Z 조그 · 자동 이동(언제나 Z 를 먼저 맨 위로)은 상관없다.
- **보정 점 추가**: [보정 점 추가] → [크게 보기] 창에서 핀이 실제로 있는 자리를 눌러 [추가](스테이지는 안 움직임). 누른 자리(지금 변환으로 계산한 X · Y)와 핀 위치가
  "보정 점 허용 거리"(10 mm)보다 멀면 거절 · 기존 점에서 "보정 점 같은 자리 기준"(3 mm) 안이면 추가하지 않고 그 점을 교체한다. [마지막 지우기] 로 되돌린다. 알림 "보정 점 추가 · 2개 · 계산 위치와 2.06 mm 보정".
- **좌표 변환 = 보정 점 우선**: 꼭짓점 4개는 대략의 방향 · 크기(바탕)만 잡고, 보정 점은 그 자리를 정확히 지나며 둘레는 가까운 보정 점의 보정량을 거리 가중(1/거리²)으로 따라간다
  (보정 점 1개면 판 전체가 그만큼 평행 이동). 꼭짓점이 덜 간 채 등록돼도 찍은 샘플은 0.25 mm 안팎(모의 계산 · 예전 최소제곱 0.63~1.03 mm). 초기 설정 5 목록의 "보정 n mm" = 그 점의 보정량.
- **핀 놓을 자리**: 샘플마다 핀 사각형이 윤곽 안에 가장 넉넉히 들어가는 자리(삼각형 · 사다리꼴은 넓은 쪽) - 측정 · 순회 · 샘플 이동이 그 자리로 간다(판 사진에 가는 사각형).
- **빈 판 사진 정렬**: 두 사진이 실제로 다른 곳(샘플)을 빼고 맞춘다(샘플이 많으면 정렬이 샘플에 끌려가 사진 한 장 검출로 넘어가 얼룩을 샘플로 잡았다). 로그에 "다른 곳 n %".
- **설정 조합 검사**: 저장할 때와 측정 시작 · 재개 때 같이 쓰면 안 되는 조합을 이유와 함께 거절한다. 예) 측정 간격 + 읽기 시간이 온도 못 읽음 허용 시간(3초)의 70 % 를 넘음 ·
  냉각 끝 온도가 가열 끝 온도 이상 · 가열 무반응 시간이 열선 연속 최대 시간 이상 · 가열 속도로 계산한 가열 시간이 한 단계 시간 한도 이상 · 릴레이 역할 겹침.
- **측정 시작에 카메라는 필요 없다**(촬영 · 샘플 검출만 카메라를 쓴다).
- **사용 안 할 포트**(전체 설정 "연결", 기본 COM4): 선택 상자에 "(사용 안 함)" 으로 보이고 고를 수 없다. [연결] · 자동 연결 모두 열지 않는다.
- 설정 기본값이 바뀌어도 `settings.json` 에 저장돼 있던 값은 그대로다. 예전 값(하강 간격 0.025 · 탐색 거리 5 mm 등)이 남아 있으면 전체 설정에서 확인한다.

장비 목록은 프로그램을 실행한 컴퓨터 기준이다. 포트 · 측정 장비는 목록만 읽고 열지 않는다. 카메라는 0~3 번을 잠깐 열어 보고 열리는 것만 보인다(연결 중인 카메라는 열어 보지 않는다).
포트를 여는 것은 [연결] 과 시작 때의 자동 연결뿐이다.

## 서버 인터페이스
| 경로 | 설명 |
|---|---|
| `GET /` · `/ui/…` | 화면(ui/) |
| `GET /api/state` · `WS /ws` | 상태 한 덩어리. WS 는 바뀔 때마다 + 1 초마다 보내고 명령 `{"id", "cmd", "args"}` 을 받는다 |
| `POST /api/estop` · `/api/estop/release` | 비상정지 · 비상정지 해제(정지 뒤 2초 동안은 거절) |
| `POST /api/stop` | 이동 정지(잠그지 않는다). 명령 줄을 거치지 않고 바로 `!` 를 보낸 뒤 위치를 다시 읽는다 |
| `POST /api/cmd/{name}` | WS 와 같은 명령. 거절되면 `ok: false` 와 쉬운 한국어 한 문장 `msg` |
| `GET · PUT /api/settings` | 설정 표 · 바꾸기(전부 검증을 통과해야 저장. 측정 중에는 못 바꾼다) |
| `GET /api/camera/preview.jpg` · `/api/img/{what}.jpg` | 카메라 미리보기 · 찍은 사진(raw 원본 · crop 조각 · plate 보정한 판 사진 · empty 빈 판 사진) |
| `GET /api/run/points?sample=&from=` | 측정 중인 샘플의 점(새 점만) |
| `GET /api/results` · `/api/results/record?id=` · `/api/results/points?id=&sample=` | 측정 기록 목록 · 기록 하나 · 점 |
| `POST /api/results/png?id=` | 그래프 그림(PNG)을 그 기록 폴더에 저장 |

명령 이름은 `app/control.py` 의 `COMMANDS` 표에 있다(연결 · 장비 목록 `devices_refresh` · 이동 · 릴레이 · 히트건 `heater_on` · `heater_off` · `heater_element` · 읽기 · 초기 설정 단계 · 측정 · 결과 · 폴더 선택 `pick_folder` ·
샘플 이동 `sample_goto(id, lower)` · `plate_goto(x, y, view, lower)` · 자동 순회 `tour_start` · `tour_stop`).

## 시험
```
python -m compileall -q app tests run.py
python -m pytest -q       # 시험용 장비(tests/fakes/)만 쓴다. 실제 포트 · VISA · 카메라를 열지 않는다. Linux 약 2 분 · Windows 노트북 약 4 분
node --check ui/core.js   # 화면 JS 는 문법 검사까지만(ui/*.js 모두)
```
프로그램에는 실장비 방식 하나뿐이다. 시험용 장비는 `tests/fakes/` 에 있고, 시험(`tests/conftest.py`)이 프로그램의 "장비를 꽂는 자리"에 꽂아 쓴다.
화면(브라우저)은 이 시험에 들어 있지 않다. 화면 확인은 따로 한다.
컴퓨터 속도에 따라 결과가 바뀌는 판정(점 간격 · 받은 점 수 · 부하 아래 경보)은 고정 숫자가 아니라 실제 기록을 기준으로 본다.
히트건을 쓰는 시험은 끝날 때마다 시험용 히트건에 인터락 오류(송풍 먼저 → 열선)와 송풍 단독 켜짐이 없었는지 확인한다.
